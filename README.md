# Central Surgical Concern Pvt. Ltd. — Business Website

A responsive, multi-page website for **Central Surgical Concern**, a medical equipment importer based in Kathmandu, Nepal (operating since 2012).

Built from scratch with plain **HTML and CSS** — no frameworks or site builders.

## Pages

| Page | Contents |
|---|---|
| `index.html` | Hero section, product categories, why choose us, call to action |
| `about.html` | Company story, mission, values and team |
| `products.html` | Full catalogue: surgical instruments, ICU & critical care, hospital furniture, disposables, oxygen systems, waste management |
| `contact.html` | Contact details and enquiry form |

## Features

- Responsive layout that works on desktop, tablet and mobile
- Shared stylesheet (`style.css`) for consistent design across pages
- Product catalogue organised by category with images
- Contact form with input validation (required fields, email type)

## Tech

`HTML5` · `CSS3` · `Responsive design` · `Git`

## Run it locally

No install needed. Clone the repo and open `index.html` in a browser:

```bash
git clone https://github.com/xitiz-r/centralsurgical.git
cd centralsurgical
open index.html   # macOS  (Windows: start index.html)
```
